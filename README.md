# Система учёта заявок

Учебный проект по дисциплине «Технологии разработки программного обеспечения».

## Назначение

Система предназначена для регистрации, обработки, распределения и контроля заявок.

## Пользователи

- Администратор — управление пользователями и настройками системы.
- Оператор — регистрация и обработка заявок.
- Исполнитель — выполнение назначенных заявок.
- Заявитель — создание заявок и просмотр их статуса.

## Структура проекта

```text
docs/       — техническая документация и диаграммы
src/        — исходный код проекта
tests/      — автоматизированные тесты
database/   — схема БД, тестовые данные и SQL-запросы
```

## База данных

Для лабораторной работы №5 используется SQLite. Скрипты находятся в `database/`:
- `schema.sql` — создание таблиц и ограничений;
- `seed.sql` — заполнение тестовыми данными;
- `queries.sql` — примеры SELECT, WHERE и JOIN;
- `dml_test.sql` — отдельные проверочные UPDATE и DELETE с откатом транзакции.

Подробности: [`docs/lab5-database.md`](docs/lab5-database.md).

## Контроль версий

Проект разрабатывается с использованием Git.
Основные ветки проекта:
- `main` — основная стабильная ветка;
- `develop` — ветка текущей разработки.
