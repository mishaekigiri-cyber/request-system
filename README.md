# Система учёта заявок

Учебный проект по дисциплине «Технологии разработки программного обеспечения».

Автор: **Привалов М.Ф., ИСИП-407**

## Назначение

Система предназначена для регистрации, обработки, распределения и контроля заявок.

## Роли пользователей

- **Администратор** — управление пользователями и настройками.
- **Оператор** — регистрация и обработка заявок.
- **Исполнитель** — выполнение назначенных заявок.
- **Заявитель** — создание заявок и просмотр их статуса.

## Реализовано в лабораторной работе №6

- создание, просмотр и редактирование заявок;
- поиск по теме, описанию и имени заявителя;
- фильтрация по статусу и категории;
- изменение статуса заявки;
- проверка входных данных и связанных сущностей;
- SQLite и воспроизводимые демонстрационные данные: 10 заявок, 5 пользователей, 4 категории и 4 статуса;
- базовый веб-интерфейс и автоматические тесты.

## Структура

```text
docs/              документация, журнал ИИ и чек-лист
src/models.py      модели и проверка данных
src/database.py    SQLite, схема и начальные данные
src/services.py    бизнес-логика заявок
src/main.py        веб-интерфейс и HTTP-маршруты
tests/             автоматические проверки
database/          SQL-схема и демонстрационные запросы
```

## Запуск в Windows PowerShell

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
uvicorn src.main:app --reload
```

Откройте `http://127.0.0.1:8000/`. Документация HTTP-маршрутов доступна по адресу `http://127.0.0.1:8000/docs`, проверка состояния — `http://127.0.0.1:8000/health`.

При первом старте создаётся локальная база `data/requests.sqlite3`. Для другого пути задайте переменную окружения `REQUESTS_DB_PATH`. Локальная база исключена из Git; тестовые данные создаются кодом и также описаны SQL-скриптами.

## Тесты

```powershell
pytest -q
```

Тесты используют временную SQLite-базу. Список ручных проверок находится в `docs/lab6-checklist.md`; журнал применения ИИ — в `docs/ai_log.md`.
