# Лабораторная работа №5 — база данных

Проект: **Система учёта заявок**  
Автор: **Привалов М.Ф., ИСИП-407**

## Состав базы

Используется SQLite и пять таблиц:
- `Users` — пользователи и роли;
- `Requests` — заявки;
- `Statuses` — справочник статусов;
- `Categories` — справочник категорий;
- `Comments` — комментарии к заявкам.

## Файлы

- `database/schema.sql` — создание таблиц и ограничений;
- `database/seed.sql` — тестовые данные;
- `database/queries.sql` — примеры SELECT, WHERE, JOIN, UPDATE и DELETE.

## Запуск

Откройте SQLite в корне репозитория и выполните скрипты в таком порядке:

1. `.read database/schema.sql`
2. `.read database/seed.sql`
3. `.read database/queries.sql`

В DB Browser for SQLite можно открыть `database/schema.sql` и `database/seed.sql` через вкладку Execute SQL и выполнить их последовательно.

## Примечание

UPDATE и DELETE оставлены закомментированными, чтобы при обычном запуске не менять и не удалять демонстрационные записи. Снимки экрана выполнения запросов и готовая бинарная SQLite-база должны быть добавлены отдельно при наличии этих файлов в локальном проекте.
