# Лабораторная работа №6 — ручная проверка

Автор: **Привалов М.Ф., ИСИП-407**

Запуск из корня репозитория:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
uvicorn src.main:app --reload
```

Откройте `http://127.0.0.1:8000/` в браузере. При первом запуске SQLite-файл создаётся автоматически в `data/requests.sqlite3`, а справочники и десять заявок загружаются повторяемым способом. Путь можно переопределить переменной окружения `REQUESTS_DB_PATH`.

## Чек-лист

- [ ] Главная страница открывается без ошибки.
- [ ] Список содержит не менее десяти демонстрационных заявок.
- [ ] Фильтр по статусу ограничивает список выбранным статусом.
- [ ] Фильтр по категории ограничивает список выбранной категорией.
- [ ] Поиск находит заявки по теме, описанию или имени заявителя.
- [ ] Новая заявка сохраняется и появляется в списке со статусом «Новая».
- [ ] Нельзя создать заявку с пустой или слишком короткой темой/описанием.
- [ ] Изменение статуса заявки сохраняется после обновления списка.
- [ ] API возвращает 404 для отсутствующей заявки и 422 для некорректного формата данных.
- [ ] `/health` возвращает `{"status":"ok"}`.
- [ ] При перезапуске приложения существующая локальная база не заполняется повторно.

## Автоматизированная проверка

```powershell
pip install -r requirements.txt
pytest -q
```

Тесты используют временную SQLite-базу и не должны изменять пользовательский файл данных.
