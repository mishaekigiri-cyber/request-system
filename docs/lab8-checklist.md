## Контейнеризация

- [ ] Создать локальный файл конфигурации: скопировать `.env.example` в `.env`.
- [ ] Проверить, что `.env` не отслеживается Git.
- [ ] Собрать образ: `docker compose build`.
- [ ] Запустить контейнер: `docker compose up -d`.
- [ ] Проверить состояние: `docker compose ps`.
- [ ] Проверить логи: `docker compose logs --tail=100 request-system`.
- [ ] Проверить `http://localhost:8000/health` (или порт из `.env`).
- [ ] Проверить `/docs`, список заявок, создание и изменение заявки.

- [ ] Остановить приложение: `docker compose down`; не удалять volume без необходимости.
